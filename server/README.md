# FuzzForge API Service

This is a simple Express.js API proxy for the FuzzForge application.

## Deployment

This API is designed to be deployed to Render.com as a free web service.

## Environment Variables

- `PORT`: Port number (default: 3002)
- `MISTRAL_API_KEY`: API key for Mistral AI integration
- `FRONTEND_URL`: URL of the frontend application for CORS configuration
